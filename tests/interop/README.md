# Interoperability

Use the Java driver shared with the Rust SDK. In the `opentdf-rust-sdk`
checkout, open `tests/interop/java/README.md` for the commands and
`tests/interop/java/local-kas.md` for the test server setup.

Run the Rust checkout's `tests/interop/matrix.sh` with this checkout's path
to include both SDKs and Java in the same test.
